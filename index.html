สถานะและการตั้งค่า

การล้างข้อมูลในอุปกรณ์จะไม่ลบข้อมูลในฐานข้อมูลออนไลน์

วิธีติดตั้งฐานข้อมูลออนไลน์

  1. สร้างโปรเจกต์ Supabase แล้วเปิด SQL Editor
  2. เปิดไฟล์ supabase.sql ในชุดติดตั้ง คัดลอกทั้งหมดไป Run
  3. ไปที่ Settings → API คัดลอก Project URL และ Publishable/anon key มาใส่ด้านบน
  4. สมัครบัญชี/เข้าสู่ระบบ จากนั้นบันทึกข้อมูลเพื่อซิงก์หลายอุปกรณ์
  5. ทดสอบด้วยบัญชีผู้ใช้สองบัญชี เพื่อยืนยันว่าไม่เห็นข้อมูลข้ามบัญชี ก่อนใส่เอกสารจริง
